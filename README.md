# YOLO Pothole Segmentation Model

A pothole segmentation project using **YOLO11m-Seg** to detect and segment potholes in road images.

### Features
- Train and validate the segmentation model.
- Predict potholes with confidence scores.
- Export the trained model to ONNX format.

### Technologies
Python, Ultralytics YOLO11, PyTorch, ONNX.

### Model Configuration
- Model: `yolo11m-seg.pt`
- Epochs: 30
- Image Size: 640 × 640
- Batch Size: 16

### Applications
Automated road inspection, pothole detection, and road damage assessment.
